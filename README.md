# 口琴模拟器 Harmonica Simulator

一个 Windows 桌面的 **8 孔口琴指法模拟器**：
导入 MIDI，把音符映射成 8 个音键加鼠标修饰键，可以在本地试听、
跟着谱子练习，也可以导出成宏文件。

> ⚠️ **使用前请先读 [DISCLAIMER.md](DISCLAIMER.md)。**
> 本项目会模拟键盘与鼠标输入。这类行为在绝大多数在线游戏的用户协议中
> 属于被禁止的自动化操作，**可能导致账号被封禁**。
> **请只在离线、单人或练习场景使用，严禁用于任何在线对局。**

---

## 这是什么

- 把 MIDI 文件解析成时间轴上的音符序列；
- 把每个音高映射到「8 个音键 + 鼠标左/中/右修饰键」的口琴指法；
- 支持移调、八度折叠、多声部优先级、去除开头空拍等处理；
- 可以本地试听、显示跟谱、导出按键乐谱与厂商宏文件。

它**不是**外挂：不读写任何进程内存、不注入 DLL、不 hook 键盘、
不修改任何程序的数据，只使用 Windows 公开的 `SendInput` API 产生输入事件，
性质与罗技 / 雷蛇自带的宏软件相同。

---

## 功能

| 功能 | 说明 |
|---|---|
| 打开 MIDI | 支持 `.mid` / `.midi`，可选主旋律轨 |
| 口琴映射 | 32 个音位（8 音键 × 修饰键组合），自动八度折叠 |
| 原曲试听 | 用 Windows 自带 GM 音源播放原曲，便于对比 |
| 一键移调 | 自动搜索让"可奏音符最多、缺音最少"的移调量 |
| 卷帘编辑 | 直接改音高、改时值、框选、撤销重做 |
| 实时 MIDI 演奏 | 接 MIDI 键盘，直接映射成口琴指法 |
| 导出 | 文本乐谱、按键表 CSV、雷蛇 XML、罗技 Lua、MIDI |
| 自定义热键 | 开始/暂停/继续、后退 5 秒、前进 5 秒，都能改 |
| 无残留 | 不写注册表、不自启动、不联网 |

## 编译

只需要 Windows 自带的 .NET Framework 4.x 编译器，**不需要安装任何 SDK 或第三方库**。

```bat
:: 在仓库根目录执行
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe ^
  /nologo /t:winexe ^
  /out:HarpSimulator.exe ^
  /r:System.Windows.Forms.dll /r:System.Drawing.dll ^
  /codepage:65001 /utf8output ^
  src\HarpSimulator.cs
```

编译完双击 `HarpSimulator.exe` 即可。

> ⚠️ **杀毒软件误报说明**
> 部分杀毒软件（已确认的有卡巴斯基）会把这类"模拟输入"的程序判为可疑，
> 报出的名字通常是 `VHO:Worm.Win32.Convagent.gen`、`VHO:Trojan.MSIL.Agent.gen`、
> `VHO:Backdoor.MSIL.XWorm.gen` 这类带 **`VHO`（启发式可疑对象）** 或
> **`.gen`（泛化规则）** 标记的名称 —— 它们不是具体病毒的特征码。
>
> 原因：`SendInput`（发送按键）+ `GetAsyncKeyState`（读按键）+ `RegisterHotKey`（全局热键）
> 这组接口既是宏软件的特征，也是键盘记录器的特征，加上 exe 没有数字签名，
> 云保护就从严判定。罗技 G HUB、雷蛇 Synapse、AutoHotkey 编译的脚本都长期被误报。
>
> **这不是病毒。** 可自行核实：搜索源码或 exe 字符串，确认没有任何
> 自启动、传播、联网下载、进程注入、注册表写入的代码。
> 详见仓库内的说明或 `docs/` 目录。

## 使用

1. 双击运行。
2. 点「打开 MIDI」选一个你有权使用的 MIDI 文件。
3. 在左侧点一行作为主旋律。
4. 需要的话调移调、八度折叠、速度、倒计时。
5. 点「开始 F6」，或直接按 **F6**。
6. 播放中再按一次 F6 暂停，再按一次继续。

### 默认热键

| 键 | 动作 |
|---|---|
| **F6** | 空闲 = 开始；播放中 = 暂停；暂停中 = 继续 |
| **F5** | 后退 5 秒 |
| **F7** | 前进 5 秒 |

三个键都可以在界面右上角的「自定义热键…」里改，
支持 F1~F12、字母、数字以及 Ctrl / Alt / Shift 组合键。
改完存在 `设置.ini`，下次打开自动沿用。

### 音域与指法

```
音键    Z  X  C  V  B  N  M  ,        简谱 1 2 3 4 5 6 7 1̇
鼠标左键  按住 = 整排降一个八度
鼠标右键  按住 = 整排升一个八度
鼠标中键  按住 = 整排升半音
音域 = 低音 do 到高高音 #do（超出范围的音自动空拍）
```

## 常见问题

**Q: 程序会不会读写别的程序的内存？**
A: 不会。全部源码公开，可以自行搜索确认：没有任何
`OpenProcess` / `ReadProcessMemory` / `WriteProcessMemory` / `CreateRemoteThread` 调用。
只用了 `SendInput` 产生输入事件。

**Q: 为什么杀毒软件报毒？**
A: 这是"模拟输入"类程序的常见启发式误报。本项目不联网、不自启动、
不写注册表、不释放任何文件。可以自行编译一份对比。

**Q: 会不会被检测到、会不会封号？**
A: 本项目**不做任何反检测处理**，也**不承诺**"防封""过检测""不会被发现"。
使用自动化输入在多数在线游戏中都属于违规行为，**有封号风险**，
包括长期封禁与设备封禁。请自行判断并承担后果。

**Q: 支持哪些 MIDI？**
A: 标准 MIDI 1.0 文件（`.mid` / `.midi`）。打击乐轨通常没有稳定音高，
建议选用旋律轨。
