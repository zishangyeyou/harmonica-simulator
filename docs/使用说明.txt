口琴模拟器 · 导出格式说明
==============================

本文件说明「导出乐谱 / 宏」功能会生成哪些文件，以及各文件的用途与格式。

一、软件功能（供对照）
1. 桌面程序，内置 Windows GM 口琴音色（Program 22）。
2. 「口琴映射」模式：单旋律，8 孔指法，GM 口琴音色。
3. 「原曲试听」模式：全通道多声部，GM 钢琴音色，用于对照原编曲。

二、音域与指法
8 孔音域：C3–C#6（MIDI 48–85）。
音键：Z X C V B N M ,    （对应简谱 1 2 3 4 5 6 7 1̇）
鼠标：不按 = 基准  左 = 低八度  右 = 高八度  中 = 升半音

「八度折叠」默认开启：超出范围的音自动折到最近八度，整首不换调。
开启折叠后，绝大多数单旋律曲目都可以完整演奏，不会出现缺音。

三、推荐用法
1. 「打开 MIDI」选一个你有权使用的 MIDI 文件（本仓库不附带任何示例曲目）。
2. 在左侧点一行作为主旋律。通常选音符最多、音域最集中的那一条。
3. 移调保持 0、八度折叠保持开启即可；可先用「一键移调」看有没有更优解。
4. 若曲目音域明显超出，开启折叠后仍会有一部分音无法演奏，属于正常现象。

四、导出内容
点「导出乐谱/宏」后，所有文件会保存到程序目录下的 MIDI 文件夹：

  乐谱.txt              纯文本乐谱，含音名、时值、指法
  按键表.csv            通用格式（时刻 / 动作 / 目标），可给其它宏工具使用
  macro-razer.csv       雷蛇 Synapse 可导入的宏（CSV 形式）
  macro-razer.xml       雷蛇 Synapse 可导入的宏（XML 形式）
  macro-logitech.lua    罗技 G HUB 脚本
  <原文件名>.mid        随附的 MIDI 副本

导入说明：
· 雷蛇：Synapse 3 → 宏 → 导入 macro-razer.xml / .csv。
· 罗技：G HUB → 选中设备 → 编写脚本 → 把 macro-logitech.lua 整段粘贴 → 绑定触发键。

五、输入兼容档位
目标程序通常按帧采样按键。修饰键（鼠标左 / 中 / 右）必须比音键早一点按下，
否则两者会被折进同一帧，导致漏音或变调。

  稳健    给 30fps 与卡顿场景留更多余量，出现漏音时优先选它
  标准    60fps 的推荐值（默认）
  极限    给高帧率、追求最紧时序的场景

导出的宏文件会按当前所选档位生成时序，保证与软件内演奏一致。
